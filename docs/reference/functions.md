# Function Reference

Complete API reference for SystemChecks functions.

## Public Functions

Functions will be documented here as they are developed.

### Get-Help

For detailed help on any function:

```powershell
Get-Help <FunctionName> -Detailed
Get-Help <FunctionName> -Examples
Get-Help <FunctionName> -Full
```

### List All Functions

```powershell
Get-Command -Module systemchecks
```

## Function Categories

Functions will be organized by category:

- **Check Management**: Creating and managing checks
- **Validators**: Validation logic
- **Reporters**: Result formatting and output
- **Utilities**: Helper functions
