A PowerShell module for building comprehensive system checks and health validations.

## Overview

SystemChecks provides a framework for creating, organizing, and executing diagnostic checks across various system components and infrastructure. It's designed to help system administrators, DevOps engineers, and IT professionals build robust validation frameworks.

## Key Features

- **Modular Design**: Build reusable check components that can be combined and extended
- **Flexible Framework**: Support for various types of system validations
- **PowerShell Native**: Leverages PowerShell 7.4+ features for modern scripting
- **Extensible**: Easy to extend with custom check types and validators
- **Well-Tested**: Comprehensive test coverage using Pester
- **Cross-Platform**: Works on Windows, Linux, and macOS
